# MINEINTEL Data Directory

This directory is reserved for sample mining documents, test datasets, and reference files used during OCR, text extraction, chunking, and embedding workflows.

Supported document types:
- PDF (Native reports, geological surveys, mine plans)
- Scanned PDF (CMPDI technical reports requiring OCR)
- DOCX (Mining project reports, memos)
- Excel (XLSX/XLS tabular production data, coal quality metrics)
- Images (PNG/JPEG map scans, borehole diagrams)
